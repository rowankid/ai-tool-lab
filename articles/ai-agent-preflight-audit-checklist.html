Agent Safety / Workflow

AI Agent 自动化前的任务审计清单：Claude Code / Codex 版

披露：本文不包含 Claude/Anthropic 或 OpenAI/Codex 的联盟链接。目的不是“追求全自动”，而是把自动化边界和验证写清楚。

一句话结论

Claude Code、Codex 这类 agentic coding 工具可以读代码库、改文件、跑命令。 真正的风险不在“它会不会写”，而在“你有没有把任务边界、权限、数据与验证写清楚”。 在你按下执行前，先用这份审计清单把不可逆风险拦在门外。

适合谁 / 不适合谁

  • 适合：维护静态站、内容库、脚本化发布流程；希望把“重复性改动 + 可验证结果”交给 Agent。
  • 不适合：把“注册/登录/验证码/KYC/付款/投放/外部发帖”交给 Agent；或希望在没有验证与回滚的情况下批量改站。

先看 3 个官方事实：权限模式不是装饰项

  • Claude Code 的权限系统是分层的：官方文档把工具大致分成只读、Bash 和文件修改三类，后两类默认都可能需要审批。
  • Permission modes 至少有 4 种常见模式：default、acceptEdits、plan、 bypassPermissions；它们不是“效率选项”，而是风险边界。
  • Plan Mode 适合先看后改：Anthropic 的 common workflows 文档明确把它用于读代码、规划复杂改动和安全 review； 对内容站来说，它很适合先做题库盘点、链接审计和改动计划。

审计清单（发布前 15 分钟）

  1. 任务是否可验证？ 给出可检查的验收标准：新增页面能被解析、站内链接不死、sitemap 更新、curl 返回 200、标题匹配。
  2. 是否拆成“可回滚的小步”？ 一次只做一个主题簇或一个页面；避免“一口气生成 20 篇”。
  3. 是否明确人工边界？ 写清楚：验证码、登录、注册、外部发布、购买、收款、税务/KYC、删除数据、`--delete` 同步等必须人工确认。
  4. 是否限制写入范围？ 只允许改 `ai-affiliate-site/`、`codex/wiki/01-项目/AI联盟内容收益实验/` 这类明确目录；禁止改 `.secrets/`、账号配置与未授权截图目录。
  5. 是否限制命令范围？ 优先只允许只读命令（`rg`、`ls`、`cat`）+ 明确可验证命令（HTML 检查、链接检查、测试）。
  6. 是否明确“不可访问外网”的前提？ 如果当前环境无法联网，就不要让 Agent “查官网并引用最新版本”；改成“只写方法与检查表，链接官方来源”。
  7. 是否预先列出需要更新的文件清单？ 例如：新增文章页、更新首页文章列表、更新 sitemap、更新题库状态、更新看板与数据表。
  8. 是否先过“thin content”风险门槛？ 每篇内容至少：首段结论、3 个事实核查点、中文用户角度、适合/不适合、替代方案、3 个内部链接。
  9. 是否准备回滚点？ 在大改动前确保 git 工作区干净；改动后先本地校验，再提交。
  10. 是否有发布后的“复检动作”？ 同步到 `/tmp` 发布目录做快照；本地起 HTTP server 用 curl 验证新增页面 200 与标题存在。

一个可直接复用的“安全任务模板”

把下面 5 句写进你的任务描述，能显著降低误改和返工：

  • 目标：只新增 1 篇文章页，并接入首页、sitemap、题库与看板。
  • 边界：不做登录/注册/验证码/KYC/付款/外部发布；不改 secrets 与账号配置。
  • 验证：HTML 解析、站内链接检查、`rsync` 到 `/tmp`、本地 curl 200 + 标题校验。
  • 质量：首段结论 + 事实核查点 + 中文用户角度 + 适合/不适合 + 3+ 内链。
  • 提交：通过校验后再 git commit；不要提交 `.env`、token 或截图。

内容站场景下，权限模式怎么选

  • plan：先用于盘点文章、找死链、列修改计划、审查题库状态。适合“先研究再决定要不要改”的小时迭代。
  • default：适合单篇文章补来源、补内链、补 FAQ 这种中低风险改动；仍然保留逐步确认。
  • acceptEdits：只适合你已经写清范围、文件集和验证命令的批量改动，例如统一披露文案、修 canonical、补 sitemap 入口。
  • bypassPermissions：不适合公开站点发布链路。除非环境完全可控、任务完全可回滚，否则不要把它当成默认选择。

一个务实原则是：如果任务里出现“登录、付款、验证码、删除、大范围同步、外部发布”任一关键词，就别把权限模式往更激进方向切。
