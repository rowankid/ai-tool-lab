tool paths

如果你是带着工具问题来的

SEO/GEO

Frase、Contentpen、Outwrite 怎么选

适合正在比较 AI SEO/GEO 工具的人，重点看工作流位置，而不是只看佣金比例。

 Agent

Taskade vs Notion/Coda

适合想把选题、任务、资料和 Agent 协作放进一个执行台的小团队。

 Repurpose

YouTube 长视频转 SEO 文章

适合已经有视频、直播或播客素材，想先沉淀站内搜索资产，再切短内容的人。

 Podcast

播客转博客的 AI 工作流

适合已经有访谈、播客或长音频，想先整理 transcript，再检查 web/email 差异后接成博客与 newsletter 的人。

 Ops

Codex automations 边界

适合已经开始跑定时任务，但还没把“哪些能自动做、哪些必须人工停住”写成公开 SOP 的人。

 Scheduler

Claude vs Codex 定时任务怎么选

适合已经知道自己要自动化，但还没分清会话内、本地、云端和同线程持续推进差异的人。

 Briefs

Codex 运营简报怎么做

适合已经有碎片上下文、周报、手机审批和待决策问题，但还没把它们收束成一页可判断简报的人。

 Loop

内容生产闭环怎么搭

适合已经补了 `/goal`、automations、事实源和简报，但还没把规格、执行和验证接成同一条循环的人。

 Newsletter

Substack vs beehiiv

适合想把搜索与社媒流量沉淀成邮件列表、再做内容变现的人。

 Welcome

欢迎邮件 5 封序列

适合已经有订阅入口、想把“第一次访问”接成 7 天回访关系的人。

 Network

Newsletter 推荐网络怎么用

适合已经准备做 newsletter 增长，但还没想清 Top 4 活跃门槛、不能靠“不显示”退出网络，以及 Welcome page endorsement 边界的人。

 Signup

beehiiv 订阅弹窗怎么选

适合已经有站内文章和订阅入口，但分不清 Content Gate、Popup 与 None 应该怎么分工的人。

 Compliance

 Reviews

 Queue
